# 🛒 Task 5 - TechKart E-Commerce Website

## 📌 Overview

TechKart is a responsive e-commerce web application developed using HTML, CSS, and JavaScript. It demonstrates product listing, product details, shopping cart functionality, LocalStorage, and responsive web design.

---

## ✨ Features

- Responsive Design
- Product Listing
- Product Details Page
- Shopping Cart
- LocalStorage
- Search Products
- Category Filter
- About Page
- Contact Page
- Modular Folder Structure

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

---

## 📁 Folder Structure

```
Task-5-Ecommerce/
│── css/
│── data/
│── js/
│── index.html
│── products.html
│── product.html
│── cart.html
│── about.html
│── contact.html
```

---

## 🚀 How to Run

1. Download the repository.
2. Open the `Task-5-Ecommerce` folder.
3. Run `index.html` in your browser.
