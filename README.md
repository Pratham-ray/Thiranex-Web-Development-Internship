# 🚀 Thiranex Web Development Internship

Welcome to my official repository for the **Web Development Internship at Thiranex**. This repository contains the complete collection of projects and tasks I built throughout the program to strengthen my frontend development skills.

---

## 📂 Completed Projects

### 📌 Task 1 – Portfolio Website
* **Description:** A foundational multi-page personal portfolio website.
* **Key Features:**
  * Multi-page architecture including About, Projects, and Contact pages.
  * Built using semantic HTML5 and styled with CSS3.

### 📌 Task 2 – Responsive Portfolio
* **Description:** An advanced, mobile-friendly evolution of the personal portfolio featuring modern UI/UX principles.
* **Key Features:**
  * Fully responsive layouts built using **CSS Flexbox** and **CSS Grid**.
  * Integrated **Dark Mode** support for enhanced user comfort.
  * Improved design aesthetics and interactive elements.

### 📌 Task 3 – To-Do App
* **Description:** A dynamic task management application.
* **Key Features:**
  * Interactive UI for adding, editing, and deleting tasks using **JavaScript**.
  * DOM manipulation and event handling.
  * Local storage integration to persist user data across sessions.

### 📌 Task 4 – Weather Dashboard
* **Description:** A real-time weather tracking application.
* **Key Features:**
  * Integration with a third-party Weather API using modern JavaScript (`fetch`, `async/await`).
  * Dynamic DOM updates to display current weather conditions and forecasts.
  * Search functionality for different cities and responsive UI.

### 📌 Task 5 – E-Commerce Website
* **Description:** A comprehensive frontend interface for an online store.
* **Key Features:**
  * Complex, responsive grid layouts for product catalogs.
  * Dynamic shopping cart functionality (adding/removing items, calculating totals).
  * Interactive elements like image carousels, modals, and hover states.
