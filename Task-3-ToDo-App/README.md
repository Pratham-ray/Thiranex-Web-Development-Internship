# ✅ Task 3 - To-Do Application

## 📌 Overview

A simple and interactive To-Do List application developed using HTML, CSS, and JavaScript. Users can add, complete, and delete tasks with LocalStorage support.

## ✨ Features

- Add Tasks
- Delete Tasks
- Mark Completed
- Task Counter
- LocalStorage Support
- Responsive UI
